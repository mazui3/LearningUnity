A router[a] is a computer and networking device that forwards data packets between computer networks, including internetworks such as the global Internet.\
Routers perform the traffic directing functions on the Internet. A router is connected to two or more data lines from different IP networks.

查这个是因为最近班装配了NAS。

NAS means "Network Attached Storage".\
This essentially means its a hard drive that is attached to a network and it's accessible over the network.

But at home, one of the cheapest ways to run a NAS is with a router and an external hard drive.\
A LOT of routers these days have a USB port on them that you can plug in an external hard drive to.\
Then, using any computer that can access the router, you can access the hard drive, over the network.\
Tada! You have a very basic NAS.
