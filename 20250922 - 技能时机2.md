回合制游戏中有不同的时机，每个时机有不同的method需要处理。\
很有道理。\
一看代码它是写进一个回调array里了。

```
/// <summary>
/// 没有指定事件类型类型的回调函数
/// </summary>
private readonly PEventDelegate delegates = new();

/// <summary>
/// 指定了特定事件的回调函数
/// </summary>
private readonly Dictionary<PEvent, PEventDelegate> pointedDelegate = new();

private readonly AfterPEventDelegate delegatesAfterPEvent = new();
```

到使用的时候，是这样的。\
用PEvent来invoke包括在array里的method。
```
public static void OnPiecesEvent(PEvent e, DataBundle db)
{
    Instance.delegates.Invoke(e, db);
    if (Instance.pointedDelegate.ContainsKey(e))
    {
        Instance.pointedDelegate[e].Invoke(e, db);
    }
    db.recovery()
    Instance.delegatesAfterPEvent.Invoke();
}
```
