一个商品要贩卖，使用的是SKU（计费点）。在游戏里会给商品连上SKU，在上架平台用SKU对照商品价格。

在游戏中发起支付，（在RuStore中）使用SKU当作product id，向平台申请购买。

这时候平台方会反馈一个receipt（在Rustore中是Receipt Id是Purchase Id）。

这个Receipt包括了付款是否成功，用户id等必要信息。

结果很简单。
```cs
Action<RuStoreError> onError = (error) => {
    LogKit.E("RuStore: Purchase onError");
    OnRuStorePaymentException(error);
};
                
Action<ProductPurchaseResult> onSuccess = (result) => {
    LogKit.I("RuStore: Purchase onSuccess");
    LogKit.I("Purchase Id" + result.purchaseId);
    //发放道具

};

RuStorePayClient.Instance.Purchase(parameters, PreferredPurchaseType.ONE_STEP, SdkTheme.LIGHT, onError, onSuccess);
```

public abstract class BaseValue<T> {

    public T value { get; }

    protected BaseValue(T value) {
        this.value = value;
    }

    public override bool Equals(object obj) {
        if (obj is BaseValue<T> other) {
            return EqualityComparer<T>.Default.Equals(value, other.value);
        }

        return false;
    }

    public override int GetHashCode() => value?.GetHashCode() ?? 0;
