看游戏开始时，一般挂一个Init或者GameManager，专门用于启动（&处理）游戏的空gameObject。\
老项目写在了MainCamera里，我觉得不是很好但是有道理（在说什么）。

这个Init写的挺干净
```cs
private void Start()
{
  DontDestroyOnLoad(gameObject);

  //这里的singleton是游戏必要模块
  //EventSystem
  //TimeInfo
  //ObjectPool
  //IDGenerator
  //CoroutineLockComponent
  Game.AddSingleton<theRequireModule>();
  
  Task.ExceptionHandler += Log.Error;

  StartGame();

  Thread.CurrentThread.CurrentCulture = new System.Globalization.CultureInfo("en-US");
  LocalizationManager.Init();//语言
  LoadConfigData();//读表

  //这里的init大多是给插件，打点用的，广告用的
  InitRequireModule();

  AudioManager.m_MusicPlayer = Camera.main.GetComponent<AudioSource>();
  Application.targetFrameRate = 60;
  QuestWebTime();//获取Web服务器时间
}
```

里面的一些细节之后再看，俺觉得很神秘的是，它的StartGame()，不是真正的StartGame。\
